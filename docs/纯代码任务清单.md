## P1 · 显示三模式 + 实时频谱 + 真李萨如 —— 拓展③（1 天）

现在屏上固定是"波形 + 包络 + 色块 + 键盘"，拓展③要求的**实时频谱**和**李萨如图形**
都没有。而且 272 行已经排满，硬塞会挤掉现有内容。

| 子项 | 内容 |
|---|---|
| P1a 模式切换 | `lcd_scope` 增 `input [1:0] disp_mode`；**长按 `key_btn`（Key_2）1 秒**循环切换：0=波形+包络（现状，默认）、1=频谱+包络、2=李萨如+包络、3=诊断（保持现有色块/灰阶用于上板验色） |
| P1b 实时频谱 | 新增 `rtl/display/spectrum.v`：8 带 **Goertzel**（比 FFT 省、只算能量）。中心频率取 130/260/520/1k/2k/4k/8k/16k Hz，`N=1024`（分辨率 47 Hz），24 位累加 + 饱和防爆。柱状绘制直接复用 `lcd_scope` 的倒数乘法列索引 |
| P1c 真李萨如 | 先说清：现在的"相位图"是**单声道 sample vs 上一拍**的相轨迹，不是李萨如。真李萨如要 X=L、Y=R。所以先给 `mixer16` / `audio_out` 加**声像**：声部 i 按 i/(VOICES-1) 分到 L/R（`l * (VOICES-1-i) + r * i` 之类），左右声道内容不同，X-Y 才是图形 |
| 屏幕布局 | 模式 1/2 复用现成的 `y48..111`（示波器区）与 `y112..175`（柱区），不改行分界，只换数据源 → 布局风险最低 |
| TB | 扩 `sim/tb_inst.v`：三种模式各断言一个代表性像素块的点亮数区间 |
| 风险 | 声像会改变**听感**（声音变宽）。默认给"声像=居中"，只在模式 2 用到 L/R 差异时才展开？不行——李萨如需要实时差异。折中：默认声像轻微展开（±20%），听感变化很小但图形明显 |

## P2 · 表情与效果 —— 拓展②（1 天）

拓展②要求"≥3 维表情（力度/滑音/颤音）+ ≥2 种音色 + 板内混响延迟合唱"。
现在有 ≥2 种音色（4 种）✅，其余全缺。力度做不了（TTP229 二值），改补**滑音 + 颤音**凑满 3 维。

| 子项 | 内容 |
|---|---|
| P2a 滑音 | `rtl/audio/portamento.v`：`note` 变化时 inc 不跳变，按指数逼近目标（时间常数 ~60 ms）。**注意**：inc 是 32 位，逼近要用 `inc += (target-inc)>>k`，k 决定速度 |
| P2b 颤音 | `rtl/_reserved/vibrato_lfo.v` 转正：**乘性**调制 `inc * (1024±DEPTH) >> 10`，5 Hz，±17 cent。LFO 相位各声部共用（听感自然） |
| P2c 板内延迟/混响 | `rtl/audio/fx_echo.v` 转正：单抽头反馈延迟，D=1446 (30 ms)，g=0.4，2048×16 BSRAM（2 块）。**反馈路径必须打拍**，否则 Fmax 掉到 60 MHz 以下 |
| 开关 | 长按 `vup_sw` 0.8 秒循环：`FX0 全关 / FX1 颤音 / FX2 延迟 / FX3 颤音+延迟`，状态条显示 `VIB` / `DLY` |
| TB | `tb_portamento`（阶跃后 X 样本内到达 90%）、扩 `tb_inst`（颤音时 inc 有周期抖动、延迟后输出比干声晚 1446 样本） |
| 风险 | 延迟写回会自激，必须软限幅；BSRAM 从 4/46 涨到 6/46，仍在预算内 |

## P3 · 多波表 —— 评分①加固（半天）

**要解决的问题**：现在 32 个分量读的是**同一张**正弦表，严格按"单波表查表只计 1 个振荡器"
可能被判 1 个。给每个分量一张不同内容的表，坐实"独立发声单元"。

| 项 | 内容 |
|---|---|
| 生成 | `rtl/audio/tri_1024.mem`（三角）、`saw_1024.mem`（锯齿）、`sqr_1024.mem`（方波，带限）、`harm2_1024.mem`（二次谐波为主）。**全部归一化到 ±32767**，否则分量音量失衡 |
| 新增 | `rtl/audio/wavetable_bank.v` 转正：`sel[1:0]` 选表，寄存器输出 |
| 改 `osc_bank` | 分量 k 读第 k 张表（k=0 正弦、1 三角、2 锯齿、3 方波）→ **会改变音色**。所以做成**新音色档**：`timbre` 从 2 位扩到 3 位，第 8 档 = 多波表合奏，原 4 档音色**逐位不变** |
| 兼容性 | 原 4 种音色的输出必须**逐样本一致**（用改动前的 tb_inst 波形断言守住） |
| 资源 | BSRAM 从 4 涨到 4+4=8/46（每表 16 Kbit，pROM 4 块）。可接受 |
| TB | `tb_wavetable`（4 表峰值都 = 32767/32768、内容两两不同）；`tb_inst` 加"旧音色输出不变"回归 |

## 7. 建议执行顺序与里程碑

```
P0 现场测试模式        → 里程碑 1：评分③ 有据可依（最重要，先做）
P3 多波表              → 里程碑 2：评分① 加固（放前面因为会动 osc_bank 核心）

P1 三模式+频谱+李萨如  → 里程碑 4：拓展③ 从"部分"变"达标"
P4 LED 指引 / P5 UART  → 里程碑 5：拓展④（受硬件制约）
```

**为什么 P3 排在 P2/P1 前面**：它要改 `osc_bank` 的读表通路，动的是最核心、最容易掉
Fmax 的地方。先把它做完并重新收敛时序，后面 P1/P2 的改动才有一个稳定的基线可以比。

每个里程碑结束时跑一遍：
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\run_all_sim.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build_inst.ps1
```
并把资源/Fmax 记到 `docs/里程碑记录.md`，方便以后回退定位。

   严格说不算李萨如，评委可能不认。
