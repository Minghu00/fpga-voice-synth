|---|---|
| P2a 滑音 | 没新建 `portamento.v`，直接做进 `osc_bank.v` 的帧尾预计算流水（每帧只有 8 声部一次，成本极低）。`tgt_inc` 阶梯，`inc_org[v] += (tgt - inc_org[v]) >>> 8`，5 次到 87%、20 次到 99%，时间常数 **≈95 ms**；目标由「最近进入的键」`glide_idx`（3 位，按 `key_rise` 优先级编码）给出 |

## P3 · 多波表 —— 评分①加固（半天）✅ **已完成**

**要解决的问题**：原来 32 个分量读的是**同一张**正弦表，严格按"单波表查表只计 1 个振荡器"
可能被判 1 个。给每个分量一张不同内容的表，坐实"独立发声单元"。

> **状态**：24 项断言全过 / 9 个平台全绿 / Logic 2875（14%）· Register 1282（8%）·
> BSRAM 7/46（16%）· **Fmax 124.043 MHz**（比 P0 的 119.647 还高 4.4 MHz）·
> 最差 setup slack +1.198 ns / **35 个管脚一个都没动** / 0 告警 / 位流 7,264,154 B。
> 证据文档：`docs/多波表证据.md`。

| 项 | 实际做法 |
|---|---|
| 生成 | 四张表**合成一个文件** `rtl/audio/wav_bank_4096.mem`（4096 行 × 16 bit），四段各 1024 行：正弦 / 三角 / 锯齿 / 方波。三张新表**全部带宽限到 8 次谐波**（避免不必要的混叠），归一化到峰值 32767 |
| 兼容性 | **第 0 段与旧 `sine_1024.mem` 重新生成后逐行 0 处不同** → `wave_mode=0` 时四个原音色的声音**逐位不变** |
| 新增 | `rtl/audio/wavetable_bank.v`（删掉 `sine_rom.v`）：`tab_sel[1:0]` + `addr[9:0]` → `{tab_sel,addr}` 寻址 **一块 4096×16 BSRAM**，读延迟仍 1 拍、单读端口 |
| 改 `osc_bank` | `wire [1:0] tab_nx = wave_mode ? cidx : 2'd0;` + `tab_q` 与 `rom_a` 同时打拍；`wave_mode=1` 时幅度改成 `{8192,8192,8192,8192}`（各 0.25） |
| 进入方式 | **长按 Key_3（D7）约 0.79 s** 切换，粘性保持，断电退出。短按仍是音量 +1。零新增管脚 |
| 屏幕 | 状态条 `x 192..215` 橙色块 = WAVE 生效（顺手修掉了 P0 的 TEST 红块覆盖 216 px、右半边重复点亮两个缺陷）|
| 资源 | BSRAM 4 → **7/46（16%）**，逻辑 +91 LUT、寄存器 +23。**Fmax 反而 +4.4 MHz**（BSRAM 同步读替掉了紧的组合路径）|
| TB | `sim/tb_wavetable.v`：**4096 个 (tab,addr) 点逐个与 `.mem` 比对，0 处不符** + 6 个校验点 + "四表确实不同" + "读延迟恰好 1 拍"；`tb_osc_bank` 加 2 项选表断言；`tb_inst` 加 5 项长按/短按断言 |
