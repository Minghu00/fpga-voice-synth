# 显示页证据 —— 波形页 / 频谱页

> 对应赛题 **拓展③ 可视化交互**：音符触发时波形 / 频谱 / 李萨如可视反馈。
> 本文记录已经实现并验证的部分：**波形页**与**实时频谱页**。
> 李萨如页尚未实现（需要左右声道分离），见文末「未完成」。

## 1. 一句话结论

长按 Key_2 超过 **1.6 s** 在「波形页」和「频谱页」之间切换，屏幕上出现
紫色的显示页阶梯（状态条 x = 320..367 两格），当前页那一格点亮。

| 页 | 画面 | 数据来源 |
|---|---|---|
| 0 波形页 | y 28..163 的实时波形 + y 164..231 的包络曲线 + y 240..271 的 16 根柱 | `mix_out` / `env_flat` |
| 1 频谱页 | y 28..163 的 16 根频谱柱（每根 30 px） | `spectrum16` 的 4 bit × 16 电平 |

零新增管脚：切页复用 Key_2 的长按手势。

## 2. 三种按键时长（Key_2，`key_btn` / T2）

| 按住时长 | 动作 |
|---|---|
| < 0.8 s | 锁存模式开关（原有） |
| 0.8 s .. 1.6 s | 表情档 FX 步进（原有，P2） |
| **> 1.6 s** | **显示页切换（本次新增）** |

实现：`keymap8` 里的 `hcnt` 在去抖后的按下期间计数，`BTHR = 38 000`（约 0.79 s）、
`VTHR_C = 2 * BTHR`（约 1.58 s），分别产生 `btn_press`（0.8 s 单脉冲）与
`btn_vlong`（1.6 s 单脉冲）。`top_inst` 里：

```verilog
if (btn_vlong) dmode <= ~dmode;
```

`dmode` 现在是 **1 bit**（当前只有两页）。以后加李萨如页时扩回 2 bit 并把
`lcd_scope` 的 `dm_on` 比较宽度同步加宽。

## 3. 频谱页的实现要点

### 3.1 为什么不用 radix-2 FFT

屏幕是逐行扫描、没有帧缓存，一帧只需要 16 个数。为此：

- 全 512 点 radix-2 FFT 需要 log2(512) = 9 级蝶形、一个 512×32 的中间存储和
  复数旋转因子表，LUT 代价远超收益；
- 直接算 16 个频点的 DFT 只需要 **2 个 BSRAM（sin/cos 表）+ 2 个乘法器 +
  16 组 32 位累加器**；
- 每个采样要算 16 个频点 × 2 个乘积，共 32 次乘加。用**时隙流水**：一个采样
  用 16 个时隙 × 2 拍 = 80 个时钟（预算是 2240 个时钟／采样，占用 3.6%），
  两个乘法器轮流服务 sin 和 cos。

结果：16 bin，覆盖 **94.17 Hz .. 1.507 kHz**（k = 1..16，k × 48214.29 / 512）。

### 3.2 三个必须记住的坑（都踩过）

| 坑 | 现象 | 原因 | 修法 |
|---|---|---|---|
| **cos 相移用错** | 单音却点亮整排 | 写成 `N/2`；`sin(p + N/2) = -sin(p)`，等于把 cos 表读反 | 必须 `sin(p + N/4)` |
| **无保留的乘积截断** | 电平整体低 60 dB | `xq <= xin * win >>> 8;` 里乘法宽度由 16 位赋值目标决定，高 8 位在移位前就丢了 | 给乘积一个显式 24 位 net |
| **32 位累加器溢出** | 单个音符糊满整个屏 | 满幅音在 bin 中心时一个乘积就是 2^30，512 个累加到了 2^39 | 乘积先 `>>10` 预缩放 |

### 3.3 三角窗

矩形窗下，偏离 bin 中心的音会按 Dirichlet 核的 1/df 泄漏，C4 距最近 bin 中心
2.78 个 bin 时连 bin 16 还有 −22 dB，整排都亮。三角窗把远端旁瓣压低约 13 dB，
代价为零（就是采样计数器在 256 处折返）。

```verilog
wire [7:0] win = scnt[8] ? (8'd255 - scnt[7:0]) : scnt[7:0];
```

### 3.4 自动电平（AGC）

`mix_out` 实际只有几千 counts，固定的绝对门限要么全黑要么全亮。改成以
**本块的峰值 bin 为基准、每档 3 dB**：

```
level = 15 - (ref - msb) * 2      // 1 msb = 6 dB，所以 2 个电平／msb
```

低于峰值 45 dB 的一律读 0，这就是旁瓣和量化噪声不出现在屏上的原因。

## 5. 综合与时序

| 项 | P2 后（`64ab42c`） | 本次（P1 显示页） |
|---|---|---|
| Logic | 3378/20736 (17%) | **3671/20736 (18%)** = 2989 LUT + 580 ALU |
| Register | — | **1703/16173 (11%)** = FF 1675 + I/O FF 28 |
| CLS | — | 2418/10368 (24%) |
| I/O Port | 35/207 | **35/207 (17%)** —— **未变** |
| BSRAM | 7/46 (16%) | **13/46 (29%)** = 7 SDPB + 6 pROM（sin/cos 表各 1 + 波表 4）|
| DSP | 3/24 | **6/24 (25%)** = 10 MULT18X18 + 1 MULTALU36X18 |
| 告警 | 0 | **0** |
| Fmax | 116.540 MHz | **108.437 MHz**（logic level 8）|

### 余量不足的说明（必须写清楚）

Fmax 从 116.5 掉到 **108.44 MHz**，对 108 MHz 约束只剩 **+0.037 ns**。原因是
`spectrum16` 是一个大算术块（2 个乘法器 + 16 组 32 位累加器 + 32 位优先级
编码器），在补齐过程中修掉了三条真实违例：

| 轮次 | 最差路径 | Fmax |
|---|---|---|
| 初版 | `u_spec/re_*/DO -> u_spec/ref/CE`（累加器 → 32 位加 → 优先级编码 → 比较 → CE） | **59.3 MHz** |
| 第 1 轮：`msb_d` 寄存器化比较 | `DO -> msb_d/D` | 74.0 MHz |
| 第 2 轮：每槽 2 拍（先寄存幅度再做编码） | `DO -> mag_q/D`（两次 32 位加串联） | 98.2 MHz |
| 第 3 轮：每槽 3 拍（abs / add / encode 分开） | `u_lcd/mult/DOUT -> nr/D`（频谱柱高） | 104.6 MHz |
| 第 4 轮：柱高提前一级译码（`slvl_q` / `stop_q`） | `u_frame/fc -> u_spec/re/CE` | **108.44 MHz** |

**结论：时序收敛（TNS 0，0 违例），但仅 0.037 ns 余量。** 这是全工程最紧的
一处，量产前若要求 5% 以上余量，下一步应把 `spectrum16` 的 16 组累加器改成
时分复用单累加器 + 16 字 BSRAM，或把 N 从 512 降到 256。

## 6. 现场怎么看

1. 上电，屏幕进入**波形页**：底部 16 个白键格 + 波形 + 包络 + 16 根环境柱。
2. 长按 Key_2（T2）**超过 1.6 秒**松手 → 状态条 x 320..335 的紫色格点亮，
   画面切成**频谱页**：16 根柱，左边低音、右边高音。
3. 按触摸键，低频键点亮左边的柱，高频键点亮右边的柱。
4. 再长按 1.6 秒 → 回到波形页。

## 7. 未完成 / 已知限制

- **李萨如页尚未实现**。真李萨如需要 X = 左声道、Y = 右声道，目前 `wave_buf`
  是单通道（只存 `mix_out`），且混音是单声道。实现路径：给 8 个声部加
  ±20% 声像 → `mixer16` 输出左右两路 → `wave_buf` 双通道 → 相位页画
  (L, R) 点。用户已同意该声像方案（m05690）。
- 频谱只到 16 bin、1.507 kHz 以上看不到；这是为了不占 LUT 的取舍。
- 频谱页的 16 根柱是 16 个固定频点，不是 1/3 倍频程分析。
- 三角窗的旁瓣抑制约 13 dB，比 Hann 窗的 31 dB 差，但零成本。
